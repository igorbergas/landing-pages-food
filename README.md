# 🍔 Landing Pages Food

Uma landing page moderna e responsiva para um restaurante, desenvolvida com HTML, CSS e JavaScript. O projeto foi criado com foco em uma interface intuitiva, design atrativo e boa experiência do usuário.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery
- ScrollReveal.js
- Font Awesome

---

## ✨ Funcionalidades

- ✅ Layout totalmente responsivo
- ✅ Menu de navegação responsivo
- ✅ Animações ao rolar a página
- ✅ Sessão de cardápio
- ✅ Sessão de depoimentos
- ✅ Botões de redes sociais
- ✅ Interface moderna e intuitiva

## 🖥️ Como executar

Clone o repositório:

```bash
git clone https://github.com/igorbergas/landing-pages-food.git
```

Entre na pasta:

```bash
cd landing-pages-food
```

Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** do Visual Studio Code.
